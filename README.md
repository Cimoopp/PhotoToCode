# PhotoToCode

Приложение превращает любую картинку в код. Работает локально, без интернета.
Один и тот же код собирается в **APK для Android** и **EXE для Windows**.

## Режимы

| Режим | Что на выходе |
|:---|:---|
| base64 → HTML | готовая строка `<img src="data:...">` |
| base64 → PHP | PHP-файл с data-URI картинки |
| base64 → CSS | правило `background-image: url("data:...")` |
| base64 → чистая строка | сам base64 (PNG без потерь) |
| ASCII-арт | текст из символов |
| SVG — цветной | вектор с настраиваемым числом цветов |
| SVG — чёрно-белый | двухцветный контурный вектор |

## Скачать готовые файлы

Раздел **Releases** → тег `latest-build`:

* `PhotoToCode.exe` — Windows, запускается двойным щелчком;
* `PhotoToCode-debug.apk` — Android, включите «Установка из неизвестных источников».

Файлы появляются автоматически: при каждом коммите в `main` запускается
сборка (вкладка **Actions**). Первая сборка APK долгая — buildozer скачивает
Android SDK и NDK (~2 ГБ), это 30–60 минут. Дальше благодаря кэшу быстрее.

## Запуск из исходников

```bash
pip install kivy pillow
python main.py
```

Сборка EXE вручную:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name PhotoToCode main.py
```

Сборка APK вручную (Linux или WSL):

```bash
pip install buildozer
buildozer android debug      # файл появится в bin/
```

## Как пользоваться

1. **Выбрать картинку** — PNG, JPG, WEBP, BMP, GIF, TIFF и др.
2. Выбрать режим в списке.
3. Подвинуть ползунки: детализацию (размер обработки), число цветов SVG
   или ширину ASCII.
4. **Преобразовать** → результат появится в поле ниже.
5. **Копировать** — в буфер обмена, **Сохранить** — в файл.

Куда сохраняется файл:

* Android: `/storage/emulated/0/Download/PhotoToCode/`
* Windows: папка `PhotoToCode` в домашнем каталоге пользователя.

## Полезно знать

* base64 всегда примерно на треть больше исходного файла: 3 байта → 4 символа.
  Поэтому большие фото автоматически уменьшаются (ползунок «Детализация»).
* Чем меньше «Детализация» и число цветов, тем меньше файл SVG.
  Для логотипов и схем ставьте 2–6 цветов, для фото — 8–16.
* Предпросмотр в окне показывает первые 20 000 символов, в файл пишется
  результат целиком.
* HEIC (фото iPhone) поддерживается, только если установлена библиотека
  `pillow-heif` (`pip install pillow-heif`) — в APK она не входит.
* Обработка идёт в отдельном потоке, окно не подвисает.
